# De la Glosa a la Calle (P149)
Entiende qué cambia en el presupuesto de un programa público, revisa las fuentes y dimensiona sus montos con referencias de compras públicas.

Compara bases presupuestarias explícitas, identifica datos no disponibles y permite revisar el cálculo y sus límites. Las equivalencias son escenarios para comprender una magnitud; no demuestran prestaciones perdidas ni impactos observados.

La cobertura se calcula desde el conjunto cargado. La portada identifica la selección mostrada; `data/presupuesto2027.json` y su documentación exportada describen el conjunto completo del candidato.

Desplegado en: `https://delaglosaalacalle.evegat.cl`
